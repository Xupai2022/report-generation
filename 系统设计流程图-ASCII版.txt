================================================================================
                          【并发控制机制】
================================================================================

┌───────────────────────────────────────────────────────────────────────────┐
│                          Semaphore限流控制                                 │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  限制：最多3个并发LLM请求                                                 │
│                                                                           │
│  实现：                                                                   │
│  ┌─────────────────────────────────────────────────────────┐             │
│  │ llm_semaphore = asyncio.Semaphore(3)                   │             │
│  │                                                         │             │
│  │ async with llm_semaphore:                              │             │
│  │     # 获得槽位，执行LLM调用                             │             │
│  │     result = await loop.run_in_executor(...)           │             │
│  │     # 自动释放槽位                                      │             │
│  └─────────────────────────────────────────────────────────┘             │
│                                                                           │
│  场景：                                                                   │
│  • 第1-3个请求：立即获得槽位，并行执行                                    │
│  • 第4个请求：等待队列，直到前3个中有1个完成                              │
│  • 记录等待数：logger.info(f"当前等待: {waiting_count}")                  │
│                                                                           │
│  健康检查：                                                               │
│  GET /health 返回当前并发状态：                                           │
│  {                                                                        │
│    "llm_concurrency": {                                                  │
│      "max_concurrent_requests": 3,                                       │
│      "available_slots": 1,      # 当前可用槽位                            │
│      "active_requests": 2,      # 当前活跃请求                            │
│      "is_saturated": false      # 是否已满                               │
│    }                                                                      │
│  }                                                                        │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│                          FileLock文件锁保护                                │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  目的：防止多用户同时读写同一文件                                         │
│                                                                           │
│  应用场景：                                                               │
│  1. 渲染PPTX文件                                                          │
│     with FileLock(report_path, timeout=60):                              │
│         ppt_generator.render(slidespec, report_path)                     │
│                                                                           │
│  2. 保存SlideSpec JSON                                                   │
│     with FileLock(slidespec_path, timeout=60):                           │
│         slidespec.save(slidespec_path)                                   │
│                                                                           │
│  3. 重新生成report (从slidespec)                                          │
│     with FileLock(report_path, timeout=60):                              │
│         ppt_generator.render(slidespec, report_path)                     │
│                                                                           │
│  4. 预览时复制文件                                                        │
│     with FileLock(report_path, timeout=30):                              │
│         shutil.copyfile(report_path, tmp_copy)                           │
│                                                                           │
│  实现：                                                                   │
│  • 基于文件系统的跨进程锁                                                 │
│  • 超时机制 (默认30-60秒)                                                 │
│  • 自动释放 (with语句结束)                                                │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│                          Session会话隔离                                   │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  目的：每个请求独立的工作目录，避免冲突                                   │
│                                                                           │
│  Session ID生成：                                                         │
│  ┌─────────────────────────────────────────────────────────┐             │
│  │ uuid_part = uuid.uuid4().hex[:8]                        │             │
│  │ timestamp = datetime.now().strftime('%Y%m%d%H%M%S%f')   │             │
│  │ session_id = f"{uuid_part}_{timestamp}"                │             │
│  │                                                         │             │
│  │ 示例: a3f2c5d8_20250129143022123456                     │             │
│  └─────────────────────────────────────────────────────────┘             │
│                                                                           │
│  目录结构：                                                               │
│  outputs/sessions/                                                        │
│  ├── a3f2c5d8_20250129143022123456/                                      │
│  │   ├── uploaded.xlsx            # Excel原始文件                         │

│  │   └── slidespec_mss_executive_v2.json # SlideSpec                     │

│      └── ...                                                             │
│                                                                           │
│  清理策略：                                                               │
│  • 启动时清理：超过24小时的session自动删除                                │
│  • 手动清理：POST /cleanup?max_age_hours=24                               │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘
